# 百鬼夜行 ～宵歩き～ / Night Parade: Evening Walk（Prototype v0.3）

一匹の小さな妖怪から始まり、一夜の街を旅しながら仲間を増やし、自分だけの百鬼夜行を完成させる、暖かく少し怪しい和風3D箱庭ゲーム。

- 並ぶ場所：大行列はその場。ほかの並び（扇・輪・雛壇・大騒ぎ）は、参道の入口の鳥居と、その奥の参道・神社を背にして、広場の北に南を向いて並ぶ（人数が多いほど広場の手前へ）。撮影の間だけ広場の真ん中の御神木を隠す。広場に収まらないときは近くの開けた場所

URL パラメータ：

- `?night=300` 一夜の長さ（秒、既定 1200 秒 = 20 分）
- `?seed=12345` 一夜の種。同じ種なら今夜の山札（出る Encounter と順番）・今宵の妖怪・気配の妖怪の顔ぶれが再現される。文字列も可（`?seed=今日の種`）。無指定なら毎回新しい種になり、結果画面に表示される
- `?debug` 画面上部にデバッグ表示（賑わい・最終加入からの秒数・Pacing・場の Encounter・山札・Seed・地区の状態）。キー：J 妖怪を呼ぶ／T 時間を進める／K 賑わい +15／N Encounter を出す／G 狐火の誘導／L 言霊／H 花火／O 陰陽師をすべて呼び、結界をすぐ張れるようにする

## 実装範囲（仕様書 29章 Prototype v0.1）

- **町**：商店街・長屋・寺（五重塔と墓地）・神社（目的地）・川と太鼓橋・千本鳥居と稲荷・広場の御神木・団子屋・田んぼ・妖怪横丁
- **主人公**：青い小鬼（手提げ提灯つき）。サイズは変化しない
- **行列**：先頭の軌跡を距離ベースで記録し、i 番目の妖怪は i×間隔だけ後ろの点を追う（経路探索なし）
- **妖怪 12 種と加入条件**：小鬼（触れる）／火の玉（墓地）／提灯お化け（暗い路地の提灯が灯る）／化け狸（団子）／座敷童（追いかけっこ）／猫又（何度か近づく）／河童（川辺を歩く）／唐傘お化け／ろくろ首（夜更けに出現）／天狗（十五妖を連れて稲荷へ）／化け狐（千本鳥居の報酬）／一反木綿（四十妖で空から）
- **夜行位**：独り歩き → 小行列(5) → 行列(15) → 宴(30) → 百鬼夜行(50)、百妖で特別演出
- **世界の層**：10妖 屋根の上／20妖 裏路地の妖怪祭り／30妖 妖怪船／40妖 空から／45妖 妖怪横丁の大木戸が開く
- **行列アクティビティ**：千本鳥居・太鼓橋・商店街を全員で通過、広場の御神木を一周
- **脅威**：犬・夜回り・僧侶。序盤は追われて最後尾が少し散る（すぐ戻る）→ 行列で道を譲る → 宴以降は一緒についてくる。見物人も集まる
- **音楽**：同じ曲に楽器レイヤーを重ねる（虫・風・風鈴 → 篠笛 → 三味線・琴 → 太鼓 → 鈴・拍子木・掛け声）。都節音階の合成音
- **SE**：拍子木・小鼓・鈴・笛・太鼓・木札・和紙、妖怪固有音（ぺたぺた・ぽんぽこ・ふわっ・ぼっ…）と Audio Crowd System
- **VFX**：和紙・紅葉・金箔・紙吹雪・狐火・蛍・火の粉・煙
- **カメラ**：夜行位で引いていく追従カメラ、俯瞰モード、エンディングの横からの観賞、結果後の「行列を眺める」
- **結果画面**：今宵の百鬼夜行（数・夜行位・種類・成就）

## v0.2「行列が育つほど、夜の街がこちらに応えてくる」

序盤はプレイヤーが妖怪を探す。後半は大きくなった百鬼夜行の賑わいに、妖怪の方が気付きはじめる。ただし仲間にするには、必ずプレイヤーが動く（**自動加入・放置での増加はしない**）。

- **賑わい（Festival Momentum）** `game/FestivalMomentum.ts`：新しい場所を練り歩く・地区に入る・アクティビティ成就・ランドマーク通過・長い行列での行進・加入で増える。時間経過・放置・小さく回る・壁歩きでは増えない。行列の大きさで上限が決まる（小さな行列では「熱狂」にならない）。HUD に小さな「賑わい」表示
- **Parade Attraction** `game/ParadeAttractionSystem.ts`：人数と賑わいで「気付かれる半径」「気配の頻度」「隠れた妖怪が姿を見せる条件」「Encounter が場に出る確率」が変わる。判定はすべて低頻度（0.25〜1 秒）
- **見えなかった妖怪が見える** `data/presences.ts`：6妖 くすくす笑い → 10妖 光る目 → 16妖 路地の祭囃子 → 20妖 覗く妖怪 → 30妖 遠くの行列の笛 → 42妖 高い空。世界の層（10/20/30/40/45）の間を埋める。姿を見せるだけで、加入は触れてから
- **Night Pacing Director** `game/NightPacingDirector.ts`：「歩いているのに何も起きない」時間だけを数える（放置中は数えない）。次の仕事を作る装置ではなく、迷子になりそうなときの小さな引っ掛かり。既にあるものの気配 → 狐火で方向 → 新しい噂 → 最終手段、の順（値は v0.2.1 を参照）。妖怪を直接与えることはしない
- **言霊（ことだま）** `presentation/KotodamaDirector.ts`：序盤（15 妖未満、特に独り歩き）で近くに何もないとき、光の玉がプレイヤーのそばからすすっと近くの妖怪の方へ泳いでいく（初回だけ 8〜12 秒と早め、以後は 15〜25 秒以上あける。新しい場所へ向かって歩いているときはさらに出にくい）。迷子防止であってナビではない。方向を示すだけで加入はしない
- **花火** `presentation/FireworksDirector.ts`：百妖に達すると画面奥の左右上に花火が上がり、その後もときどき一、二発。遠くの「どーん」は控えめに遅れて届き、空がほんのり明るむ。行列のいる画面中央は避ける
- **遠くの祭りの環境音**：百鬼夜行が育つほど、遠くの祭囃子（太鼓・笛・掛け声）と人のざわめき・歓声が少しずつ近づいてくる。高音を削り残響を多めにして、BGM より十分小さく。夜明けには静まる
- **ダイジェティック誘導**：笛・鈴・笑い声・太鼓・狐火・提灯の揺れ・光る目を、その場所から・その方向（左右に定位）で鳴らす／灯す。ミニマップには出さない（v0.2.1）
- **Event Deck** `data/encounters.ts` / `game/EventDeck.ts` / `game/EncounterScheduler.ts` / `game/EncounterDirector.ts`：一夜ごとに seed で山札を作る。実働は 5 種：団子を欲しがる妖怪の集団／狐火を追う／消えた提灯を順に灯す／祠の周りを行列で一周／**Mini Parade**（30妖〜。3〜8妖の小さな行列と並んで歩く、または祭り地点まで一緒に歩くと合流）
- **District Awakening** `game/DistrictAwakeningSystem.ts` + `presentation/DistrictFestivalDirector.ts`：一定規模の百鬼夜行で、地区に入ってから出るまでの一回の訪問で十分に練り歩き、最後尾まで通り抜けると、提灯が順に灯り、住民が店先に出て手を振り、屋台が開き、子供がついてくる。その地区では祭囃子が厚くなり、屋根・路地・店の裏から妖怪の気配が現れる
- **行列の偏り**：今宵の妖怪（seed）と、行列に多い種類ほど Encounter に現れやすい → 「河童の多い夜」「提灯だらけの夜」が自然に生まれる
- **称号 / 夜の記録** `data/titles.ts`：結果画面に最大 3 つ（散らずの百鬼夜行・町じゅうを祭りに・行列を呼ぶ行列・○○の大行進…）と、今夜の種

ゲームルールは `GameBus` にイベント（momentum / omen / guide / rumor / encounter* / miniParadeMerge / districtAwaken / rhythm …）を流すだけで、音・光・UI は `ParadePresentationDirector` が各 Director へ配る。

## v0.2.1「退屈はなくす。しかし、夜の余白はなくさない」

v0.2 で「後半に何もない」は解消したが、効きすぎて「提示された仕事を処理する」感覚になりやすかった。何も起きない時間をゼロにするのではなく、退屈になるほど長い空白だけを防ぐ。

- **Breathing room** `game/EncounterScheduler.ts`：Encounter が始まった直後・終わった直後は新しいものを出さない（通常 14〜22 秒、Mini Parade 後 18〜28 秒、地区覚醒後 26〜36 秒、気配が薄れた後 9〜14 秒。seed で揺らす）。その間に Pacing・賑わいから求められても、既にある気配を再提示するだけ
- **同時数**：序盤（20 妖未満）1、以降は最大 2。3 つ同時は将来の特殊な夜（辻の大祭など）だけ。二つ目の枠は埋まりにくい
- **噂（Encounter 候補）と分かれ道**：いきなり Encounter を置かず、まず遠くの音・光だけを出す。自分で近づいた噂が本物の Encounter になり、同じ組の他の噂は山札へ戻る（後で再登場しうる）。20 妖〜ときどき（後半ほど）2 方向から別々の噂が届く
- **選択が行列の個性に**：自分で追った系統の札が少し引かれやすくなり、成就した Encounter の顔ぶれが今夜の行列に少し寄る（上限つき。「気が付けば今日は狐が多い」程度）。同じ seed でも選ぶ道で違う夜になる
- **Pacing の値**：序盤 気配 18 / 誘導 28 / 噂 44 秒、中盤 16 / 26 / 38 秒、後半 14 / 24 / 36 秒。その後 24 秒ごとに誘導し直し、噂が 40 秒以上追われないまま迷い続けたときだけ最終手段で噂を本物の Encounter にする。向け先は最寄りの一つに固定しない
- **Mini Parade は珍しく**：前回から 170〜260 秒あける。同時に一つ。賑やかな行列（grand）は 55 妖〜、小さな行列に一度出会ってから、さらに間をあけて
- **地区覚醒**：一回の訪問（境目で 8 秒以内に戻れば同じ訪問）で歩いたマスだけを数える。必要なマスを約 1.35 倍にし、覚醒させた地区が増えるほど 20% ずつ増える
- **ミニマップはクエストマップにしない**：気配・狐火・Encounter の波紋は `?debug` のときだけ。通常は現在地・向き・行列の広がり・周囲の地形だけ
- **夜の波** `game/NightRhythm.ts`：静 → 気になる → 向かう → 祭り → 余韻。静かな時間は同じ曲のまま楽器を少し引き、虫・風鈴が前に出る
- **Seed**：野良妖怪の出現位置・一反木綿の舞い降りる場所・猫又の跳ねる先も seed の乱数列に（見た目の揺らぎは対象外）
- **計測** `game/NightMetrics.ts`：`?debug` で一夜の終わりに console へ（Encounter 開始・成就、Mini Parade、地区覚醒、噂・分かれ道、Omen / Guide / Kotodama の回数、30 妖以降の候補なし時間、Encounter の平均間隔、最長・平均静寂、最終妖怪数）。`game.festival.metricsReport()` でいつでも見られる

## v0.3「一夜が終わってから、自分の百鬼夜行を眺める」

クリアはゲームの終わりではない。夜が明けて（奉納して）はじめて、自分が作った百鬼夜行を完成品として眺められる。

- **After Night** `presentation/AfterNightDirector.ts` / `game/after/AfterNightState.ts`：夜 → 締めの演出（行列が立ち止まる → 太鼓・笛・拍子木 → カメラが引く → 「今宵の百鬼夜行」。約 6 秒、1.2 秒後から飛ばせる）→ 結果 → 眺める／記念撮影／絵巻。夜が終わった後は野良妖怪・脅威・Encounter・Pacing・賑わい・地区覚醒・夜の刻を止め、行列の Actor（複製しない）を並べ直してポーズを付けるだけ
- **結果**：第一画面は妖数・百鬼値・代表の役／称号・今夜の友・百妖目だけ。「今夜の記録」に三大出来事・数字・役・称号・百鬼値の内訳・今夜の地図（墨線のルート）。行き先は 眺める／記念撮影／絵巻を見る／同じ夜をもう一度（同じ seed）／次の夜（新しい seed）／タイトルへ戻る
- **NightResult** `game/after/NightResult.ts`：一夜の結果をプレーンな値にまとめる（将来 localStorage・ランキングへそのまま保存・送信できる形。今回は保存しない）
- **百鬼値（仮）**：40×√妖数 ＋ 30×種類 ＋ 25×出来事（12 まで）＋ 40×行列の遊び ＋ 50×地区 ＋ 60×合流（4 まで）＋ 2×最高の賑わい ＋ 役 ＋ 百妖 100。人数は平方根で逓減
- **役** `data/roles.ts`：今夜成立した百鬼夜行の特徴（○○の一族／大集会・百鬼揃い・水辺の一行・狐の嫁入り・提灯行列・人魂の灯籠流し・町じゅう祭り・行列が行列を呼ぶ・散らずの行進・熱狂の夜・少数精鋭）
- **Night Memory Log** `game/after/NightMemoryLog.ts` / `NightRecorder.ts`：最初の仲間・10/30/50/100 妖・百妖目（種類・時刻・地区・出来事由来か）・地区覚醒・合流・Encounter 成就・行列の遊び・世界の層・神社／夜明けを時刻つきで記録。移動ルートは 2.5 秒かつ 5 歩ごとの低頻度サンプル（最大 700 点）
- **百鬼夜行絵巻** `presentation/ResultUI.ts`：Night Memory Log を横長の和紙に時系列で並べる（判のアイコン・出来事・地区・時刻・墨線のルート・雲・判子）
- **集合写真** `game/after/PhotoFormation.ts` / `PhotoStage.ts` / `data/photo.ts`：大行列・扇の陣・祭りの輪・雛壇・大騒ぎ（データ駆動で追加できる）。大行列以外は近くの開けた場所（家・川・木を避け、手前に木の少ない向き）へふわっと集合
- **ポーズ** `game/after/PhotoPose.ts`：リグファミリー単位（CHIBI_BIPED：PHOTO_A/B/C…、CHIBI_QUAD：SIT/PAW/REST、FLOAT：FLOAT_A/B/ORBIT、SPECIAL：個別）。今は手続き的（`ProceduralPoseDriver`）、将来は同じ PoseId で正式な Rig Pose に差し替える。ポーズスタイル（はい、百鬼！／威風堂々／大騒ぎ／妖しい夜）は陣形とは独立
- **写真スタイル**：絵巻・祭・妖・素（絵巻雲・花火・紙吹雪・狐火・提灯・色味）。ゲームの状態は変えない
- **撮影・共有** `presentation/ShareTools.ts`：画面を PNG で保存（写真のみ／文字入りの共有カード）、`navigator.share` で画像と文を共有。対応していなければ画像の保存と結果の文のコピー。ファイル名 `hyakki_seed12345_112yokai.png`
- **絵巻雲** `presentation/EmakiCloudDirector.ts`：百鬼夜行が育つほど画面が絵巻に近づく。平面的な墨線の雲（すやり霞・瑞雲の渦）を、カメラに付けた板ポリのプール（夜の間 10 枚・撮影 16 枚まで）で画面の端にだけ出す。夜行位・地区覚醒・合流・五十妖・締め・陣形替えで膨らみ、百妖では「絵巻開き」（雲が寄って → 左右へ開き → 「百鬼夜行」→ 花火）

### 保存・建物の透過（v0.3 追加）

- **ブラウザに保存**（localStorage。使えない環境でも遊べる）：消音（ボタンでも M キーでも）・設定・図鑑（これまでに仲間になった妖怪と数、すべての夜の合計）・直近 10 夜の結果（`core/SaveData.ts`）。結果と図鑑はタイトルの歯車（設定）から見られる。履歴からその夜の記録・絵巻を見返し、「この種でもう一夜」で同じ種の夜を始められる

### 大妖怪・三大妖怪・隠し妖怪の基盤（v0.3 追加）

これから大妖怪（茨木童子・牛鬼・鵺…）・三大妖怪（玉藻前・大嶽丸）・隠し妖怪（ぬらりひょん）を足すための土台。今ある酒呑童子・大天狗の遊びは変えていない。

- **二つの軸**：格（`rank`：通常妖怪／大妖怪 `greater`（大天狗）／三大妖怪 `threeGreat`（酒呑童子））と、発見方式（`discovery`：通常／隠し）。隠しは格ではない（ぬらりひょんは「大妖怪で、隠し」）。大妖怪以上は一夜に一体、祓われない
- **加入条件**は条件の組み合わせ（すべて満たす）：特定の妖怪の数・行列の総数・行列の遊びの数・祭りにした地区・Encounter の成就・賑わいの段。足りないものは「小鬼あと三妖」「商店街を祭りにする」「狐火をあと一度追う」「賑わいを「熱狂」まで高める」のような短い言葉で、本人とヒントが言う
- **出現と加入は別**：町に姿と気配（酒呑童子は笑い声、大天狗は笛）がある → 会いに行く → 求めを聞く → 条件を満たして認められると加わる。気配は世界から偶然聞こえるものだけで、Pacing・狐火・言霊は大妖怪へ誘導しない。隠し妖怪は気配・ヒント・「！」でも教えない
- **今夜の候補**（`game/legends/NightLegendRoster.ts`）：一夜の始まりに seed から選ぶ（同じ seed なら同じ候補）。候補に入らなかった妖怪は今夜は町にいない。今は大妖怪・三大妖怪が一種類ずつなので毎晩いる（将来の目安：大妖怪 2〜3 種類・三大妖怪 0〜1 種類。隠し妖怪は別の抽選）。候補の一覧は画面に出さない（`?debug` だけ）

宵霞楼は湯屋らしく煌びやかに：朱の大門と提灯の参道、宿の北にそびえる高楼の灯り、赤と白の提灯の連なり、湯に浮かぶ灯籠、夜空へ昇る灯り。音楽はゆるやかな子守歌（琴と篠笛）、湯の音・「カポン」と桶を置く音・遠くの話し声と笑い声・鹿威し・風鈴・ごく微かな鈴虫が、歩く場所で聞こえ方を変える。

- **湯に入れる**：湯の縁の切れ目（踏み石・低い踏み段）から入る。湯の中はゆっくり歩き、宿泊客と同じ深さまで沈む。10 秒ほど浸かっていると、青鬼の顔がほんのり赤くなる（上がると少しずつ冷める）。入ると小さな水音と水面の輪
- **二階・三階**：畳座敷の南の壁ぞいの階段から二階（西の「霞の間」・真ん中の板の間・東の「湯煙の間」、まわりは朱の欄干と提灯）、二階の真ん中の階段から三階の望楼へ。上の階は、階段に近づいて上りはじめるまで作らず、上にいる間だけ見せる（下の階にいるときは上の階が見えない・カメラが引っかからない）。上の階にも客が泊まっていることがある

### 何夜も歩くと混ざってくる通常妖怪（v0.3 追加）

はじめは見慣れた 12 種（小鬼・火の玉・提灯お化け・化け狸・座敷童・猫又・河童・唐傘お化け・ろくろ首・天狗・化け狐・一反木綿）。夜を歩くたび・図鑑を埋めるたびに、知らなかった通常妖怪が少しずつ町に混ざりはじめる（全部で 41 種。通常妖怪は最後に 53 種）。「あれ？ こんな奴いたっけ？」と自分で気づくのが理想で、画面には「新妖怪」「第 2 段階」「レア」などの印を一切出さない（格の表示はほかの通常妖怪と同じ「妖怪」）。

- **今夜の顔ぶれ**（`game/normal/NormalNightRoster.ts`）：解禁済みから seed で数種類と、それぞれの数（一種類 1〜3 妖）。全種類が毎晩いるわけではない（wave 1 で 5 種・最後で 17 種まで）。同じ seed・同じ進み具合なら同じ顔ぶれ。wave が開いてから 2 夜は、その wave の妖怪を選びやすく、少なくとも 2 種類は入る
- **その夜に一体だけの通常妖怪**（内部の `uniquePerNight`。画面には出さない）：白沢・海坊主・テケテケ・アマビエ・鵺・八尺様・八咫烏・絡新婦・釣瓶落とし・火車・のっぺらぼう。今夜の顔ぶれに入れば町に一体だけ（報酬・Encounter からは出ない）。大妖怪ではないので、大妖怪の今夜の候補・一夜一体の枠・縁帳・加入の見出しとは関係ない（通常妖怪の総数の一体として数える）。「八尺様って一晩に一人しか見ないな」と自然に気づく程度
- 大妖怪の仕組み（今夜の候補・一夜一体・気配・特等席）には入れない。通常妖怪なので、一夜に同じ種類が何妖いてもよい。陰陽師にも祓われる
- **加入のしかた**：触れるだけにしない。既存の条件（触れる・何度か近づく・追いかける・団子・人数）に加え、どの妖怪にも使える条件を足した

| 条件 | 振る舞い | 例 |
| --- | --- | --- |
| 立ち止まる（standStill） | そばで立ち止まると向こうから寄ってくる（動いていると少し離れる） | 雪女・獏・覚 |
| 一緒に歩く（followSteps） | そばで一緒にしばらく歩くと加わる（離れるとその場で待つ） | 子泣き爺・すねこすり・磯姫 |
| 応える（respond） | 呼びかけてくる。そばで立ち止まって応えると加わる | アマビエ・うわん |
| 種類を見る（variety） | 行列の妖怪の種類がそろうと加わる | 白沢 |
| 落ちてくる（drop） | 大木の下を通ると上から降りて驚かせ、触れると加わる（痛いことはしない） | 釣瓶落とし |
| 姿を変える（gaze） | 別の姿で置き、近づくたびに次の姿へ | 目目連（障子 → 目が一つ → 目がいっぱい）・のっぺらぼう（町の人の姿 → 顔が無い） |
| 背を向ける（contrary） | 追うと逃げ、背を向けて歩くとついてくる | 天邪鬼 |
| 回り込む（sidestep） | 正面を向け続ける。脇・後ろから触れると加わる | ぬりかべ |
| 化ける（disguise） | 小鬼に化けている。妙な逃げ方をするのを追って触れると正体を現す | ムジナ |
| 高い所（perch） | 屋根の上・空にいて、近づくと降りてくる | 鵺（空の気配が開いた夜）・八咫烏（行列の遊びを二つ成し遂げた夜） |

- **出る場所・現れ方**（仮。`data/normalYokaiSecond.ts`・`normalYokaiThird.ts` の `sites`）：夜更け（雪女・テケテケ・片輪車・一本だたら・狂骨…）、気配の段階（一つ目小僧・魍魎・わいら）、地区覚醒（人魚・アマビエ・なまはげ・火車（寺町の鐘の夜）。件は地区を二つ祭りにした夜）、妖怪船（海坊主）、潜む（獏・枕返し・うわん・小豆洗い：そばでしばらく立ち止まると姿を見せる。案内・ヒント・ミニマップには出さない）、小豆洗いは「しゃっ、しゃっ」という音が近いほど大きく聞こえる（印は出さない）、絡新婦は橋のたもとの細い蜘蛛の糸を順に辿ると、その先に現れる、川辺を歩くと河童の代わりに現れる（尻こぼし）
- 姿は手続き生成の仮モデル（`characters/normalModels.ts`・`normalModelsThird.ts`）。シルエットで見分けられるように（雪女・八尺様・磯姫・絡新婦は背丈・服・髪・脚で、海坊主・ぬりかべ・ぬっぺっぽう・野槌・片輪車は形で）。血・欠損・亡骸などの表現はしない（火車は火と黒雲だけ）
- 図鑑の文は「伝承」（lore：伝承・原典の特徴だけ）と「この町での出会い方」（zukanEncounter）と「ひとこと」（zukanFlavor）に分ける（下の「妖怪図鑑」）
- 一度仲間にすれば、温泉宿「宵霞楼」の宿泊客にもなる（全員に居たがる区域と一言がある）
- 「かんきち」は出典を確かめられなかったので入れていない。「鬼」は小鬼と重なるので新しい種類にしない。ぬっぺふほふは「ぬっぺっぽう」（別名にぬっぺふほふ）。口裂け女・花子さんは本ゲームには出さない（近現代の怪談はテケテケ・八尺様だけ）
- ムジナとのっぺらぼうは別の妖怪として扱う（ムジナは別の妖怪に化けていて見破る、のっぺらぼうは町の人の姿で近づくと顔が無い）

### 行列が大きくなるほど、夜が応えてくる（v0.3 追加）

- **行列の数に誘われて現れる妖怪**：町には夜の始まりからいるが、行列が大きくなるまで姿を見せない。後から混ざる妖怪ほど大きな行列が要る（仮：段ごとに 10・20・30・45・60・75 妖、大妖怪 90 妖、三大妖怪 100 妖。はじめの 12 種はいつでも・ぬらりひょんは対象外）。数が届くと、その場所でふっと姿を見せ、「行列の賑わいに誘われて、町のどこかで何かが姿を見せた…」とだけ知らせる（名前・場所・印は出さない）。姿を見せた後は、それぞれの加入条件で仲間になる（数だけでは加わらない）。図鑑の出会い方にも、その数が載る
- **音楽が百妖まで育つ**：30 妖までの音（はじめの無音・最初の笛）はそのまま。40 小鼓 → 50 鈴・拍子木・掛け声 → 60 摺鉦 → 70 笙 → 80 琵琶 → 90 龍笛 → 100 法螺貝と、10 妖ごとに昔の鳴り物が一つずつ静かに加わり、テンポも少しずつ前のめりになる
- 値はすべて仮（`data/paradeAppear.ts`・`data/stages.ts` の `MUSIC_SWELLS`）。遊んで決める

### 妖怪図鑑（v0.3 追加）

図鑑は「一体の妖怪をじっくり見る場所」（結果の絵巻は「一夜を振り返る場所」。役割を混ぜない）。本編・設定・宵霞楼のどこから開いても同じ図鑑。

- **一体で横一列**：PC は左に姿（約 38%）・右に文、スマホ（縦画面）は 名前 → よみ・格 → 姿 → 伝承 → 出会い方 → ひとこと → 記録 の縦積み。横スクロールは出さない
- **登録済みの一枠**：名前（いちばん大きく）と格（妖怪・大妖怪・三大妖怪だけ）、よみ、別名（ある妖怪だけ）、姿（「墨絵」「3D」の札）、伝承、この町での出会い方（登録後なので加入条件を隠さない）、ひとこと、記録（これまで○妖・今夜○妖・大妖怪以上は縁を結んだ夜）。新しい保存データは増やさない
- **未登録（？？？）**：ヒントの一言だけ。名前・読み・別名・伝承・出会い方・ひとこと・墨絵・3D・姿の影を出さない。まだ町に混ざらない通常妖怪・見つけていない隠し妖怪は枠ごと無い
- **上の帳（画面の上に残る）**：題・出会った数・閉じる・名前の検索・「登録済みのみ」・区分（妖怪／大妖怪／三大妖怪）へのジャンプ。区分は絞り込みではなく目次（その区分の先頭へ移る）。通常妖怪の中に段・wave の見出しは付けない。隠し妖怪の札も作らない（ぬらりひょんは見つけた後、大妖怪の最後に現れる）。通し番号は出さない（見つけていない隠し妖怪の分が欠番になって漏れるため）
- **検索**：登録済みの妖怪だけを名前・よみ・別名で探す（カタカナ・全角半角は揃える）。未登録の？？？は検索の文字がある間は並ばない（正体を検索で推し量れない）。「登録済みのみ」は同じページの間だけ覚える（保存しない）
- **姿**：墨絵（水墨画）と 3D を妖怪ごとに切り替える。墨絵があれば墨絵が初め、無ければ 3D（今は 67 体すべてに墨絵がある。作者：さうりん）。3D は「姿を映す」を押した妖怪だけ作り、その枠の中で回す（ドラッグで回す・ピンチ／ホイールで寄る。canvas の外は図鑑をスクロールできる）。3D の姿見は図鑑全体で一つだけで、別の妖怪で映すと前の姿を片付けて移る。墨絵に切り替える・枠が画面の外へ出る・図鑑を閉じると止まる
- **正式な順**（`data/zukanOrder.ts`。並べ替えない）：通常妖怪 53 種（町に混ざる順。後から混ざる妖怪が前の妖怪の間へ割り込まない）→ 大妖怪 10 種（→ 見つけた後のぬらりひょん）→ 三大妖怪 3 体
- 閉じてもう一度開くと、同じページの間は前のスクロールの位置から

### 素材の差し替え

- **3D モデル**：`src/data/yokaiTypes.ts` の各妖怪に `modelUrl: "models/kappa.glb"` を足し、`public/models/` に GLB を置くと手続きモデルの代わりに読み込まれる（高さ 1.0 に正規化。v0.1 では静的メッシュ扱い）
- **墨絵（図鑑の水墨画）**：元絵を `art-source/yokai-ink/original/`（git に入れない）に置き、`python scripts/yokai-ink.py` で `public/yokai-ink/<ID>.webp` を作って、`src/data/yokaiInk.ts` の `INKED` に ID を足す。図鑑の UI は変えなくてよい（墨絵が初めに出る）。背景は透明・中央に一体（800×1000 の枠に比率のまま収める）。ライセンスは `LICENSES/yokai-ink.md`
- **音**：`src/presentation/audio/Instruments.ts` と `AudioDirector.ts` の関数を録音素材の再生に置き換える
- **UI**：`src/style.css` の CSS 変数と `body[data-stage]` のテーマ

### Web パフォーマンス

- キャラクターは種類ごとに 1 ソースメッシュ + InstancedMesh（頂点カラー、骨格なし）
- 距離 LOD（75 以上で小部品を省いた低ポリ、260 以上で非表示）
- 町の静的メッシュは材質ごとに結合し、灯りは夜行位ごとのグループでマテリアルを差し替える
- 遠くの野良妖怪は更新しない。散った妖怪が建物に阻まれたら屋根を飛び越えて戻る
- 読み込み：Babylon は使う部品だけ（`core/babylon.ts`）。最初に読む JS は約 1.2MB（gzip 約 310KB。以前は約 5MB）。撮影・GLB は使うときだけ読む。フォントは同梱のサブセット（使う太さだけ読まれる、合計約 1MB）

スマホの縦画面を基本に作っています（下の左に視点パッド、右に行動ボタン）。開発ルールは [CLAUDE.md](CLAUDE.md)。

## 調整待ち（ユーザー確認事項）

バランスはユーザーが実際に遊んで決める（AI は値を変えずに報告する）。一覧は [docs/architecture.md](docs/architecture.md) の「ユーザーが決めること」。今の主な論点：

- 陰陽師の厳しさ（見える距離・視野・怪しさの溜まる速さ・詠唱 1.1 秒・祓う数 三〜八・結界の長さ）
- 大妖怪（酒呑童子・大天狗）の加入条件の重さ
- 大妖怪の今夜の候補の数・縁帳から開く温泉宿の閾値・大妖怪の百鬼値（いまは 0）・見出しの一言（`data/legendConfig.ts`）、温泉宿の宿泊客の数（`data/onsen.ts`）
- 町の妖怪が多め（約 160）で、20 分の夜のうち 9〜12 分で百妖に届く
- 通常妖怪が町に混ざりはじめる条件（`data/normalYokai.ts` の `NORMAL_UNLOCK`）、新しい顔ぶれへ回す割合・一夜の種類の数・開いた直後の選ばれやすさ（`NORMAL_NIGHT`）、41 種の出る場所・加入条件の値（`data/normalYokaiSecond.ts`・`normalYokaiThird.ts`）
