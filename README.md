# 百鬼夜行 ～宵歩き～ / Night Parade: Evening Walk

一匹の小さな妖怪から始まり、一夜の街を歩きながら仲間を増やし、自分だけの百鬼夜行を眺める、和風 3D 箱庭。戦闘はなく、放置では増えない。

## 起動

```bash
npm install
npm run dev         # http://localhost:5173
npm test            # node --test
npm run build && npm run check:size
npm run preview     # http://localhost:4173
npm run fonts       # 画面の文言を足したとき（開発時だけネット）
```

`?night=300` 一夜の長さ（秒。既定 1200 = 20 分）。`?seed=12345` 同じ夜（山札・今宵の妖怪・気配）。`?debug` で状態を表示（J 妖怪 / T 時間 / K 賑わい / N Encounter / G 狐火 / L 言霊 / H 花火 / O 陰陽師）。`?onsen` は宵霞楼。

## 町と行列

商店街、長屋、寺（五重塔と墓地）、神社（奉納の目的地）、川と太鼓橋、千本鳥居と稲荷、広場の御神木、団子屋、田んぼ、妖怪横丁。主人公は青い小鬼（手提げ提灯。大きさは変わらない）。

行列は先頭の軌跡を距離で追う。間隔はふつう 1.3 歩。大きな妖怪の前後だけ体の分広がる（`game/ParadeSpacing.ts`）。

夜行位：独り歩き → 小行列(5) → 行列(15) → 宴(30) → 百鬼夜行(50)。百妖で特別演出。世界の層：10 屋根 / 20 裏路地 / 30 妖怪船 / 40 空 / 45 妖怪横丁の大木戸。行列の遊び：千本鳥居、太鼓橋、商店街、御神木一周。

脅威は犬・夜回り・僧侶。序盤は最後尾が少し散ってすぐ戻る。大きくなると道を譲り、宴以降はついてくる。

## 夜が応える

賑わい（`FestivalMomentum`）は、新しい場所・地区・遊び・ランドマーク・長い行進・加入で増える。時間経過・放置・その場での回転では増えない。小さな行列は「熱狂」にならない。

気配（`data/presences.ts`）：6 くすくす → 10 光る目 → 16 祭囃子 → 20 覗く → 30 遠くの笛 → 42 高い空。姿を見せるだけで、加入は触れてから。

Pacing は、歩いているのに何も起きない時間だけを数える（放置は数えない）。既にある気配 → 狐火 → 噂 → 最終手段。妖怪は直接渡さない。秒数（気配 / 誘導 / 噂）：序盤 18/28/44、中盤 16/26/38、後半 14/24/36。その後 24 秒ごとに誘導し直し、噂が 40 秒迷うと Encounter にする。

言霊は 15 妖未満で、近くに何もないとき、光の玉が近くの妖怪の方へ泳ぐ（初回 8〜12 秒、以後 15〜25 秒）。方向だけで加入はしない。

Encounter は seed の山札。実働は 5 種：団子、狐火、提灯、祠の一周、Mini Parade（30 妖〜。170〜260 秒に一つ）。始まった直後・終わった直後は出さない（通常 14〜22 秒、Mini Parade 後 18〜28、地区覚醒後 26〜36、気配のあと 9〜14）。同時は序盤 1、以降最大 2。噂は遠くの音と光が先で、近づくと本物になる。追った系統の札が少し出やすくなる。

地区覚醒は、一回の訪問で十分歩き、最後尾まで通り抜けると提灯・住民・屋台・子供。必要なマスは約 1.35 倍で、覚醒が多いほど 20% 増える。

百妖で画面の左右上に花火。その後もときどき。中央は避ける。ミニマップに気配・狐火・Encounter は出さない（`?debug` だけ）。

## 夜のあと

奉納すると、締め（約 6 秒。1.2 秒後から飛ばせる）→ 結果 → 眺める / 記念撮影 / 絵巻。進行は止まる。

結果の第一画面は妖数・百鬼値・役か称号・今夜の友・百妖目。記録に三大出来事・内訳・今夜の地図。行き先は眺める、撮影、絵巻、同じ種、次の夜、タイトル。

百鬼値（仮）：40×√妖数 ＋ 30×種類 ＋ 25×出来事（12 まで）＋ 40×遊び ＋ 50×地区 ＋ 60×合流（4 まで）＋ 2×最高の賑わい ＋ 役 ＋ 百妖 100。大妖怪の加点は仮で 0。

役（`data/roles.ts`）：一族、大集会、百鬼揃い、水辺、狐の嫁入り、提灯、人魂、町じゅう祭り、行列が行列を呼ぶ、散らず、熱狂、少数精鋭。称号は結果に最大 3（`data/titles.ts`）。

直近 10 夜・図鑑・消音・設定・縁帳（`hyakki.legends.v1`）・歩いた夜の数（`hyakki.normalProgress.v1`）は localStorage。使えない環境でも遊べる。

撮影の並びは大行列・扇・輪・雛壇・大騒ぎ。雛壇は三大妖怪が主人公のすぐ後ろの中央、大天狗は最後列の後ろの高い所。ポーズはリグファミリーごとの手続き（骨格はまだ無い）。スタイルは絵巻・祭・妖・素。PNG 保存と `navigator.share`。

絵巻雲は画面の端だけ（夜 10 枚、撮影 16 枚まで）。百妖で「絵巻開き」。

## 陰陽師と追いかけ

陰陽師は神社の手前と参道にいる。視野は前方 14 歩・左右 55°、背後でも 3 歩。家や木が遮る。見られると怪しさが溜まり、詠唱 1.1 秒のあいだに視線を切れば外れる。祓われると後ろから三〜八妖が町へ散る（大妖怪は祓われない）。触れれば戻る。直後 4 秒は見逃す。夜の初めは一人、四十妖か夜の半ばで二人目、夜更けに三人目。二人以上で参道に結界（半径 7.5・13 秒、休み 20〜30 秒）を張ることがある。

退散：五十妖以上（二人以上なら八十妖）／酒呑童子か大天狗／化け狐六／熱狂（三十妖以上で陰陽師が一人）。称号「陰陽師退散」。一度も祓われずに奉納すると「忍び足の百鬼夜行」。値は仮（`data/onmyoji.ts`）。

五十妖を超えると子供と犬が追いかける。行列には入らない。最大八。四十五妖を下回ると帰る。

## 図鑑

一体を横一列（スマホは縦積み）。登録済みは名前・格・よみ・別名・姿・伝承・出会い方・ひとこと・記録。未登録はヒントだけ。まだ混ざらない通常妖怪と、見つけていない隠しは枠が無い。上の帳で検索・登録済みのみ・区分へのジャンプ（絞り込みではない）。通し番号は出さない。姿は墨絵と 3D（67 体すべて墨絵あり。作者さうりん）。3D は押した一体だけ。順は通常 53 → 大妖怪 10 → ぬらりひょん → 三大妖怪 3。

## 宵霞楼

縁帳で道が開くと、タイトル・設定・結果に札が出る。別の地図で、図鑑に載った妖怪が泊まっている。歩く・見る・話す・写真・湯に入るだけ。

開く条件（仮。仲間にした種類の数）：噂は大妖怪 3。道は大妖怪 5、または大妖怪 2 と三大妖怪 1。宴会場は三大妖怪 2。最深部は三大妖怪 3 と、見つけた隠し 1。

部屋は玄関・帳場・大広間・畳座敷・縁側・中庭・内湯・露天・大岩風呂。宴会場と月見の奥庭は閉じていれば森。二階（霞の間・板の間・湯煙の間）と三階の望楼は、階段に近づくまで作らない。湯に約 10 秒浸かると顔が赤くなる。

通常妖怪を知り尽くした（wave 6 まで開き、通常の図鑑がすべて埋まった）あとの訪問で、帳場の上座に見慣れない老人がいる。話しかけるとぬらりひょんが見つかり、図鑑が増える。知らせは「新たな妖怪が図鑑に記された」だけ。その訪問のまま最深部が揃えば、奥で戸の開く音がする。

## 音

同じ曲に楽器が重なる。30 妖までは虫・風・風鈴、篠笛、三味線・琴、太鼓、鈴・拍子木・掛け声。その後（仮）：40 小鼓、50 は百鬼夜行の鈴、60 摺鉦、70 笙、80 琵琶、90 龍笛、100 法螺貝。テンポは少しずつ。静かな時間は楽器を引き、虫と風鈴が前に出る。遠くの祭りは小さく、残響多め。宵霞楼は琴と篠笛の子守歌で、場所によって湯・話し声・鹿威し・風鈴が変わる。音は合成。

建物の透過は設定で切 / 主人公とカメラ / 行列のまわりも。撮影では建物・木・NPC を分類で隠せる。

## 構成

`src/data/` 値、`src/core/` 入力・保存・seed・`babylon.ts`、`src/world/` 町、`src/characters/` 手続きモデルと Actor、`src/game/` ルール、`src/presentation/` 演出、`src/onsen/` 宵霞楼（遅延読み込み）、`tests/`、`scripts/`、`.github/workflows/`（CI と Pages）。

GLB は `modelUrl` と `public/models/`。高さ 1 に正規化し、骨格なしの静的メッシュとして使う。墨絵は `python scripts/yokai-ink.py` で `public/yokai-ink/<ID>.webp`。サーバも外部 API も使わない。

キャラは種類ごとに 1 メッシュ＋インスタンス。75 以上で低ポリ、260 以上で非表示。最初に読む JS は約 1.2MB（gzip 約 310KB）。縦画面が基本（視点パッドは左下、行動は右）。

## 調整待ち

遊んで決める。AI は値を変えない。一覧は [docs/architecture.md](docs/architecture.md) の「ユーザーが決めること」。主な論点：

- 陰陽師の厳しさ（距離・視野・怪しさ・詠唱 1.1 秒・祓う数・結界）
- 大妖怪の加入の重さ、今夜の候補数、宿の閾値、百鬼値（いま 0）
- 町の妖怪が多めで、20 分のうち 9〜12 分で百妖に届く
- 通常妖怪の解禁、今夜の割合、41 種の場所と加入の値
